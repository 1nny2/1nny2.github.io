## 星航探索与 AI 向导

进入后在左上角选择两条探索路线，随时切换，进度分别保存在当前浏览器的 localStorage。刷新会恢复选择与发现；清除网站数据会清除存档，无法存储时会提示并继续本次游戏。

- **观测星海**：调整距离与观察角度，分离核心旁的微弱回声。清晰度达到 82% 后扫描锁定，再靠近到视距 180 以内扫描确认冰蓝伴星。支持拖动/缩放和按钮操作，提示逐层揭示。回声清晰度是游戏设定，不是物理测量模型。旧版自然路线存档会重新开始，文明路线进度保留。
- **追寻回响**：在星空中选择集光器、中继环与灯塔核心（也有定位按钮）；靠近到视距 260 以内逐个扫描，取得三份接口证据，再根据能量流向连接。部件和线路随修复亮起，全部接通后出现灯塔光束；错误连接不清除已有修复。更早的未版本化文明存档会重置，版本 2 的修复进度迁移保留。
- 每条路线首版包含一个完整谜题。完成后可单独重新探索，不影响另一条路线的记录；文明路线已检查部件和已修复线路分别保存，切换或刷新不会清除。
- 测试：`npm run test:routes` 覆盖两条路线的正确/错误解法、独立存档、刷新、重玩与手机布局。

「星航向导」支持文字流式问答、停止回答、点击说话和可选语音播报。每次提问携带当前主题、探索站点、扫描状态、视距与观测记录，以及最近四轮对话。向导是游戏解说，不是视觉识别或真实天文测量系统。

少量完整指令直接操作场景：`扫描`、`下一站`、`靠近`、`远离`、`复位`、`发射流星`、`切换主题`。解释性问题、否定句及 AI 回复不会执行动作。

服务端运行 Node.js 18+，仅通过环境变量读取密钥：

```powershell
$env:OPENAI_API_KEY = '<你的密钥>'
$env:OPENAI_MODEL = 'gpt-4.1-mini' # 可选；须使用账号可访问的模型
node scripts/serve.mjs
```

不要把真实密钥放进 HTML、src、assets、浏览器存储或提交到代码仓库。`.env.example` 仅作配置说明，服务不会自动读取 `.env`；Node.js 20.6+ 可通过 `node --env-file=.env scripts/serve.mjs` 加载本机配置。前端只请求同源 `/api/guide`，服务端使用 Responses API 转发增量文字，错误响应不包含上游正文或密钥。未配置密钥时提供明确标注的本地场景提示；静态托管可游玩，但问答必须配置同源后端。

点击说话使用浏览器 SpeechRecognition（支持情况因浏览器而异），需要 HTTPS 或 localhost 和麦克风授权；识别可能经过浏览器厂商在线服务。语音播报使用系统 speechSynthesis，默认关闭。拒绝权限、不支持语音或网络失败时可继续文字操作；切后台、关闭向导或停止回答会取消语音和请求。

服务仅公开 index.html 和 assets，限制单次输入、并发和每 IP 请求频率。当前适用于本机/可信局域网；公网部署应在反向代理配置 HTTPS、身份认证及费用配额。限流为单进程内存限流。

新增验证：`npm run test:exploration`（场景流程、流式协议、停止、模拟语音、动作白名单、服务端文件访问边界）。自动化模拟上游流及语音，不代表真实账号 API 或真实麦克风验证。

## 运行与部署

已包含构建好的 `assets/`，可直接把 **index.html 和整个 assets 目录** 一起发布到静态网站，不再依赖外部 CDN。不要只上传 HTML，也不要用 `file://` 双击打开。

本地预览（Node.js 18+，不需要先安装依赖）：

```sh
node scripts/serve.mjs
```

访问 http://localhost:4173。手机连接同一 Wi-Fi 后可访问电脑的局域网 IP 和 4173 端口。局域网 HTTP 支持触摸游玩；摄像头手势需要 HTTPS（电脑本机 localhost 也可）。

## 操作

- 手机：拖动旋转、双指缩放；底部按钮切换主题或触发全部特效。
- 电脑：拖动旋转、滚轮缩放；聚焦画布后可用方向键和加减键。
- 摄像头：进入后点“开启手势”；首次下载模型时可继续游玩，也可取消。关闭手势或切到后台会释放摄像头，回到页面后需手动重新开启。
- 操作说明可展开；横竖屏布局、刘海安全区和 44px 触控区域均已处理。

## 加载与性能调整

- 移除 4 个首屏同步 MediaPipe 脚本；Three.js 固定版本并本地打包压缩。首屏仅请求应用和共享渲染模块，合计约 551KB（未启用 HTTP 压缩）。
- 手机及低核心设备基础粒子调整为约 7,240（桌面约 21,600），DPR 上限 1.25，星云精灵减半，保留核心辉光并跳过 Bloom 多通道后处理。桌面按需加载 Bloom，失败时继续基础渲染。
- 手势模型、WASM 单独放在 `assets/hands/`，约 24MB，只有主动开启摄像头后才按设备所需加载；不会在首屏预取整个目录。
- 手势推理限制为约 10–15 次/秒，避免同一视频帧重复推理；动画在后台暂停；特效对象设上限并在结束时释放。
- 建议生产静态服务器开启 Brotli/Gzip；HTML 与 app.js 使用重新验证缓存，带哈希的 chunk 可长期缓存。
