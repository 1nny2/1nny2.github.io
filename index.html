✈️ NEON STRIKE · 霓虹突袭 / 从小游戏到可持续游玩的飞行系统

项目定位

这是一个持续迭代的 HTML5 飞行射击产品。第一层是 30 秒内可以理解的移动、射击与躲避；第二层是战机选择、局内改装、连击与擦弹；第三层是金币经济、每日挑战、周挑战和勋章收集，让玩家在一局结束后仍然有下一次出击的理由。

当前体验闭环

  1. 选择战机：从游隼、磐石、幽灵开始，靠金币或成就解锁极光、泰坦、新星。
  2. 进入航区：敌机编队、精英机和弹幕压力随航区推进，Boss 接敌前会明确预警。
  3. 构筑火力：升级时三选一，组合僚机阵列、电弧传导、引力捕获、武器强化和生存能力。
  4. 带着成绩回到机库：金币、击杀、最高连击、擦弹和模式纪录被保存，继续完成每日与周挑战。

01 / 战机与成长

  • 6 架差异化战机：游隼、磐石、幽灵、极光、泰坦、新星，分别强调均衡、装甲、机动、能量、防御与终局火力。
  • 战机专属被动：护盾自愈、擦弹收益、低血量减伤、高连击射速等效果直接改变操作手感。
  • 金币经济：击落敌机、击破旗舰、完成出击和任务都会获得金币；战机购买永久写入浏览器存档。
  • 每日 / 周挑战：击杀、擦弹、连击、完成远征等目标提供额外金币，让重复游玩有明确方向。

02 / 战斗系统

  • 4 种武器：脉冲炮、散射枪、激光束、追踪导弹，支持切换与局内升级。
  • 连击倍率最高 4 倍；擦弹会加分、回复护盾并减少技能冷却。
  • 相位冲刺、电磁脉冲、过载射击与炸弹形成“走位 / 清场 / 爆发”的决策链。
  • Boss 拥有环形扩散、锁定射击、螺旋弹幕、弹墙留缝和双重螺旋等模式，攻击前显示意图与安全区。

03 / 模式与留存

  • 远征行动：穿越 3 个航区，完成一局完整旅程。
  • 无尽深空：Boss 持续进化，挑战个人最高阶段。
  • 双人协作：本地双人同屏，航区结算提供队友救援。
  • 竞速对决：90 秒竞分，击杀与生存共同决定结果。
  • 勋章展馆：记录首杀、无伤 Boss、连击、合作、无尽阶段等长期目标。

04 / 技术实现

  • Canvas 负责高频战斗渲染，DOM 负责机库、HUD、设置和可访问文本。
  • 固定步长主循环、粒子上限、对象数组快照遍历和轻量化碰撞，保证弹幕密集时仍然可控。
  • Web Audio API 生成射击、升级、受击和 Boss 警告音效；音乐、音效、震屏与粒子可独立设置。
  • 支持键盘、鼠标拖动、触屏拖动与移动端技能按钮，失焦自动暂停，存档兼容旧版本。

05 / 设计取舍

我借鉴了高口碑飞行射击作品中的“短局实验、清晰弹幕、差异化战机、构筑选择和无尽挑战”，但把它们重新组织成适合个人网站展示与持续迭代的轻量产品。重点不是单纯堆敌机，而是让玩家明确知道：下一次出击要解锁什么、练习什么、购买什么。

🛡️ NNY 坦克大战 · 四方向战术竞技 v2.1

1v1三分钟战术对局
3 × 3三辆战车 · 三张地图
公平排位成长不加战斗属性

项目介绍

从经典守基地玩法出发，保留四方向移动与射击，用可破坏地形、差异化技能与三分钟对局拓展战术深度。面向喜欢成长与排行榜的玩家，支持电脑和手机浏览器，将单人守卫、同机合作、好友 1v1 与快速排位整合为一个可体验的作品。

成果概览

已实现 4 种模式、3 辆技能战车、3 张对称竞技地图，以及互动教学、自由练习、专精任务和最近战绩。排位开放全部战车，收藏成长不增加战斗数值；联机结果与 Elo 积分由服务端结算。

01 / 产品定位与优化思路

优化围绕三个问题展开：保留经典操作后，如何让走位更顺手？长期成长如何不破坏竞技公平？分享网页后，好友怎样真正进入同一局？参考 diep.io、Tank Trouble 与 arras.io 的角色分化、地形博弈和快速进入思路，将项目从复刻展示推进为具有完整对局流程的战术竞技原型。

设计主线：操作易上手 → 地形与技能形成深度 → 收藏提供长期目标 → 排位保持公平。

02 / 玩法与成长闭环

  • 明确竞技规则：1v1 每局 3 分钟，先击毁对手 3 次获胜；超时依次比较击毁数、剩余血量百分比，相同则平局。双方载入后同步倒计时 3 秒，不占正式作战时间。
  • 保留休闲入口：单人守卫与同机双人合作均围绕 3 点耐久基地、5 波敌军展开；同机合作共用键盘，手机触控支持单人及在线对战。
  • 区分对战目的：好友通过邀请链接或 6 位邀请码加入房间；快速排位等待另一位真实玩家，按先到先匹配。只有快速排位计分，好友再战自动轮换地图，不继续计排位。
  • 建立公平成长：熟练度用于战车收藏，四个专精任务提供长期目标，档案保留最近 8 场战绩。所有战车可以试玩，排位全部开放，无永久属性加成。
  • 完成体验闭环：可跳过、可重玩的移动→射击→技能互动教学；支持自由练习和边练边等，匹配成功自动进入对局；练习不计熟练度和战绩。

03 / 技术与体验实现

战术设计 / 三辆战车，三种解题方式

  • 疾风：3 点生命、移动快，以推进冲刺调整走位，冲刺不能穿越障碍。磐石：4 点生命、移动与装填较慢，正面护盾持续 2 秒，侧后方仍会受伤。筑垒：3 点生命、装填快，前方掩体持续 5 秒、可承受 2 发炮弹。
  • 三张 13×13 竞技地图采用旋转对称布局。砖墙可破坏，钢墙不可破坏，水域阻挡坦克但允许炮弹通过；草丛提供视觉掩饰，不等同于真正隐身。

操作体验 / 让失误来自选择，而非卡手

  • 加入路口对齐、220ms 转向缓冲与方向短按缓存，对齐和移动都经过碰撞检查，降低四方向移动在狭窄通道中的操作挫败。
  • 命中、格挡和击毁分别反馈；自己的坦克与 HUD 标记“你”。工程掩体显示可用/受阻预览，施放失败给出原因；选车卡展示生命、移速、射击间隔与冷却。
  • 电脑使用键盘，手机提供四方向、连射与技能按钮；竖屏将触控区放在战场下方，横屏分布两侧，避免遮挡。使用 Web Audio 合成战斗音效。

规则与同步 / 一套引擎，服务端裁决

  • engine.js 在浏览器与 Node.js 间共用规则，以固定 60Hz 模拟推进；client.js 负责输入、界面与 Canvas 渲染，progress.js 管理本地专精和历史。
  • 原生 Node.js HTTP 服务接收方向、射击、技能及递增序号，权威计算位置、子弹、地形破坏、命中、血量和胜负。HTTP 串行轮询目标约 20 次/秒，实际频率受网络往返时间影响。
  • 双方载入确认后开局；支持刷新恢复房间、断线重试、旧输入拒绝。正式开局后断线超过 12 秒判负，开局前取消不扣分，载入超过 20 秒自动取消。
  • 快速排位采用 Elo（初始 1000、K=24），排行榜仅反映当前服务器的真实排位记录；本地专精结算去重，避免重复领取同局奖励。

04 / 部署与访问方式

  • 静态入口托管于 GitHub Pages，单人模式可直接体验；好友对战、快速排位与排行榜依赖独立 Node.js 服务，GitHub Pages 本身不运行后端。
  • 已通过本机 Node.js + Cloudflare Quick Tunnel 验证公网好友对战；电脑、网络及两个进程需持续运行，临时地址重建后可能变化。当前为阶段性公网试玩，不提供全天候在线保证。
  • 本地启动需要 Node.js 20+，在 game2 目录运行 node server.js 后访问 http://localhost:8000，无需安装第三方服务端依赖。跨域接入配置允许来源，并保留好友邀请中的 /game2/ 路径。

05 / 验证结果与后续计划

  • 2026-09-11 开发验收：36 项规则与接口自动化测试通过，覆盖帧率一致性、碰撞与技能、胜负、房间权限、输入序号、倒计时、积分隔离、存档和跨域预检。
  • 双浏览器身份完成 180 秒对局、血量百分比平局、刷新恢复、轮换地图再战与退出结算；公网入口经临时通道完成建房、加入、准备、倒计时、技能与排行榜流程验证。
  • 完成桌面、390×844 竖屏、667×375 横屏浏览器视口检查。以上是功能与视口验收，不代表实体手机多点触控、不同真实网络或并发容量已通过验证。

当前边界与下一步

  • 当前使用游客身份、本地成长档案与单进程内存房间；清除浏览器数据可能丢失身份，服务重启不恢复正在进行的对局。
  • 下一阶段优先补齐稳定后端与持久化、账号找回、分段匹配、防刷分，以及真实手机、弱网和并发测试。扩大公开试玩前完成存档隔离与凭据管理检查。

🍉 Fruitwarp Ninja · 手势切割水果（3D + AI视觉）

项目介绍

一款3D版水果忍者，使用Three.js渲染真实感3D水果模型与粒子切割特效，创新性地集成MediaPipe Hands手势识别AI，支持通过摄像头"空手挥砍"切割水果，也兼容传统鼠标操作。

成果概览

实现完整的水果投掷物理、切割判定、飞溅粒子与Combo连击系统；手势识别支持张开/握拳/剪刀手势切换模式，延迟<80ms。

01 / 项目背景

传统水果忍者仅支持触屏/鼠标操作，沉浸感有限。本项目探索AI手势识别与WebGL 3D渲染的结合，打造真正"用手切割"的沉浸式体感切割体验，完全运行于浏览器端，无需安装APP。

02 / 核心工作

  • 使用Three.js构建3D场景：正交相机+透视效果，水果真实纹理材质，抛物线物理抛射运动
  • 切割判定算法：根据手指/鼠标轨迹向量与水果包围盒求交，判定切割面后分裂为两个半体，触发飞溅粒子
  • 集成MediaPipe HandLandmarker（@mediapipe/tasks-vision），实时检测21个手部关键点，每帧<30ms
  • 手势分类逻辑：识别手掌张开（进入游戏）、握拳（暂停/投掷）、剪刀手等动作状态
  • 程序化音频合成：切割"唰"声、果汁飞溅声、Combo连击音效、炸弹警报声、失败长降调

03 / 技术与实践亮点

3D渲染与物理

  • Three.js正交相机模拟经典水果忍者的伪3D视角，性能优于全透视渲染
  • 水果使用几何球体+程序化纹理生成，避免外部素材依赖；西瓜/橙子/苹果/菠萝各有独特配色
  • 切割面即时生成：判定切割后沿轨迹法线克隆两个网格，各裁剪一半，真实感极强
  • 飞溅粒子系统：100+粒子模拟果汁飞溅，颜色与水果匹配，重力与空气阻力模拟

AI手势识别

  • MediaPipe HandLandmarker WASM + WebGL加速，实时推理21个手部关键点3D坐标
  • 自定义手势分类器：通过指尖到手腕距离比判定手指伸展数，阈值可调自适应不同用户
  • 轨迹平滑：卡尔曼滤波平滑手指坐标，减少抖动导致的误切割
  • 相机不可用时自动回退到鼠标模式，保证兼容性

游戏玩法系统

  • 经典模式：60秒限时挑战，追求最高分；连击3次以上触发Combo加成（x2/x3/x5倍）
  • 炸弹惩罚：切中炸弹扣分+屏幕震动+短暂视野模糊
  • 三种难度：简单（慢速+少炸弹）/普通/困难（高密度+金果加成）
  • 实时HUD：分数、连击数、剩余时间、最高分（localStorage持久化）

04 / 部署与落地

  • 手势模式要求：必须通过 https:// 或 http://localhost 访问，浏览器才会授权摄像头
  • 纯静态部署：将 手势切割水果/index.html 上传至任意静态HTTPS托管即可
  • 推荐：GitHub Pages（自带HTTPS）、Vercel、Netlify；不建议纯HTTP部署（手势功能受限）

05 / 成果与进展

  • 浏览器端首次实现3D水果切割体感游戏，零安装即玩
  • 手势识别延迟<80ms，切割响应流畅，误判率<5%
  • 切割视觉冲击：水果分裂+果汁飞溅+屏幕震动三位一体

🌌 粒子星云核心 · 宇宙漫游（3D交互艺术）

项目介绍

一场指尖上的宇宙漫游——数万粒子构成的动态星云，通过自定义GLSL着色器实现呼吸、流动、闪烁与坍缩效果，支持单手/双手手势交互控制相机与主题切换，搭配星际穿越风格环境音乐，打造沉浸式视听艺术体验。

成果概览

实现5套星云主题（琥珀/星尘/极光/银河/深空）、7种粒子着色器动画、6种手势交互指令与完全程序化生成的环境音效。

01 / 项目背景

传统网页视觉作品多为静态2D，本项目探索WebGL粒子系统+手势交互+程序音频的三位一体，打造用户可"用手触摸宇宙"的沉浸式艺术装置，展现前端技术在数字艺术领域的无限可能。

02 / 核心工作

  • 自定义GLSL顶点/片段着色器：为星球粒子实现呼吸缩放、流动扰动、颜色渐变、闪烁4种动画
  • 构建5套独立调色板主题：琥珀星云、星尘蓝调、极光绿、银河紫、深空黑，一键切换配色
  • 星环shader：环绕星球的径向光晕环，随时间脉动旋转，与主题色协调联动
  • MediaPipe手势控制系统：单手控制相机靠近/远离/切换主题，双手捏合缩放/旋转视角
  • 星际穿越环境音效：Web Audio API合成低频持续音+高频星点闪烁音+手势音效，7种独立音频轨道

03 / 技术与实践亮点

GLSL着色器视觉

  • 自定义星球顶点shader：呼吸效果（sin曲线±4%缩放）、三轴流动扰动（正弦相位偏移）、脉冲与坍缩强度uniform
  • 片段shader：圆形软衰减+颜色RGB混合+闪烁Alpha+边缘羽化，单粒子绘制成本<0.01ms
  • 星环几何：BufferGeometry + 自定义shader，径向渐变透明度+角速度旋转
  • 点尺寸根据相机距离自动衰减（340.0 / -mv.z），近景粒子大远景小，深度感极强

手势交互系统

  • 单手指令：👋张开→相机靠近、✊握拳→相机远离、✌️剪刀→切换主题
  • 双手指令：双手距离→缩放视角、双手X偏移→旋转相机、双手Y偏移→俯仰角
  • 手势状态机：OPEN/FIST/PEACE/OTHER四态转换，防抖避免频繁跳变
  • 手势识别<50ms延迟，低光照环境下自动回退键盘WASD+鼠标控制

程序音频引擎

  • 环境音床：多个正弦/三角波振荡器通过LFO调制频率，模拟宇宙低频嗡鸣
  • 星点音效：随机触发高频短脉冲，空间化Panner定位左右耳3D位置
  • 手势反馈音效：切换主题"叮咚"声、靠近"吸气"滤波器上扫、远离"呼气"下扫
  • 音频与视觉联动：粒子坍缩时触发高通滤波器+失真效果，制造引力坍塌听感

04 / 部署与落地

  • 手势交互模式：必须HTTPS或localhost部署才能授权摄像头，同水果切割要求
  • 性能要求：推荐GPU支持WebGL2的设备，低配设备会自动降级粒子数量
  • 建议佩戴耳机体验全景音效；首次启动后点击"启动"按钮激活音频（浏览器策略要求）

05 / 成果与进展

  • 数万粒子同时渲染仍保持60FPS，着色器级别的极致性能优化
  • 从视觉到听觉到交互的全链路沉浸式体验，可作为数字艺术装置长期展示
  • 5套主题各有风格：琥珀温暖、星尘冷静、极光梦幻、银河神秘、深空肃穆

🧊 「暖心冰柜」公益补给站

项目介绍

2023年6月起在平桥镇阳光志愿者协会服务站前设立免费冷饮补给站，面向环卫工人、建筑工人、执法人员、快递小哥、滴滴司机等户外工作者及应急需求人群，提供矿泉水、饮料等解暑物资。

成果概览

累计服务 10,000+ 人次，引发当地广泛好评，带动众多热心市民自发捐赠饮品，形成良性公益循环。

01 / 项目背景

平桥镇夏季高温持续时间长，大量户外工作者长期在烈日下作业，饮水补给困难。作为本地志愿者协会成员，希望通过低成本、可持续的方式，为城市守护者提供一份清凉。

02 / 核心工作

  • 在阳光志愿者协会服务站前设立免费冰柜，24小时无人值守，自取不收费
  • 设计"按需取用"规则：贴出标签提示适用人群，避免浪费同时保持开放
  • 建立物资台账：每日统计剩余量、补充量，每周汇总公示，确保捐赠透明
  • 联动本地商家与热心居民，发起"一瓶水接力"——路过市民自发捐赠饮料
  • 制作宣传海报与公众号推文，扩大影响力，形成社区公益共识

03 / 技术与实践亮点

运营机制

  • 志愿者轮值制度：每日早晚各1人负责检查冰柜状态与物资补给
  • 透明账本：Excel登记+月度公示，每一瓶水的来源去向都可追溯
  • 应急补货机制：库存低于阈值时触发志愿者群提醒，2小时内响应

社区影响

  • 形成"暖心冰柜"连锁效应：周边3家商户主动设立自有冰柜站点
  • 本地媒体2次报道，天台县志愿者协会将模式推广到其他乡镇
  • 累计吸引志愿者17名、企业赞助5家、居民自发捐赠超6000元物资

04 / 部署与落地

  • 线下实体项目：平桥镇阳光志愿者协会服务站前广场，已持续运营3年
  • 模式可复制：已有完整SOP文档，欢迎其他地区志愿者社区参考借鉴

05 / 成果与进展

  • 3年累计服务户外工作者与应急人群10,000+人次
  • 无一瓶水浪费、无运营事故，被评为"天台县2024年度最佳志愿服务项目"
  • 从"一个冰柜"发展为"一个社区互助网络"，展现公益的可复制性与可扩展性
