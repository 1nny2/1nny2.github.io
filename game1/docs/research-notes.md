# 霓虹突袭优化依据

本次玩法取舍基于 2026-09-12 读取的 Steam 公共商店数据与描述：

- **Sky Force Reloaded**：Very Positive，2,764 条评价；公开描述强调多阶段关卡、任务目标、可驾驶的差异化飞机、升级、收藏与本地合作。对应落地为三航区推进、战机选择、局内模块、战报与双人协作救援。
- **Minishoot' Adventures**：Overwhelmingly Positive，8,282 条评价；公开描述强调响应紧凑的操作、清晰的 bullet hell、开放探索、升级与难度/辅助选项。对应落地为更小的真实命中核心、Boss 攻击预警、擦弹奖励、自动开火、休闲/标准/王牌难度与触屏拖动。
- **Nova Drift**：Overwhelmingly Positive，14,586 条评价；公开描述强调 roguelite 单局构筑、模块化改装、短局实验和无尽模式。对应落地为三选一改装、僚机/电弧/引力三类 build 分支、重掷次数和独立模式纪录。

这里只借鉴了公开可观察的设计优点，没有复用商业美术、文案或代码。
