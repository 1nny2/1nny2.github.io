# 开发进度 · 2026-09-10 · v2.1

## 已确认要求

- 项目负责人自主开发；影响核心可玩性的取舍向甲方确认。
- 保留四方向移动射击、地形与技能、电脑和手机浏览器。
- 1v1 正式战斗 3 分钟，先击毁 3 次胜；超时先比击毁数，再比剩余血量百分比，相同平局。
- 甲方「你操作吧」已授权本轮细节优化及血量百分比规则，不再作为待决策事项。
- 长期收藏/专精不增加排位战斗属性；保留单人五波基地守卫、同机双人合作。
- 保留 NNY出品、浩源、浪尖儿社区、浪尖儿大学生社区。

## 本轮已完成

1. 双方载入后同步 3 秒倒计时；开局前不接受输入、不消耗正式战斗时间。断开或载入超过 20 秒取消且不计分。
2. 12px 路口对齐容错、220ms 转向缓冲、方向短按缓存；移动和对齐都检查碰撞。
3. 命中闪白、护盾格挡光效/音效、浮动反馈和击毁信息。
4. 工程掩体放置预览及阻挡说明，预览与技能共用规则，无效放置不消耗冷却。
5. 自己的坦克/HUD 标记，双方生命百分比显示。
6. 可跳过、可重玩的三步互动教学，以及不计分自由练习。
7. 排队时可练习；匹配成功自动进入权威对局；允许取消匹配后继续练习。
8. 战车卡展示生命、移速、射击间隔和技能冷却。
9. 四项专精任务、一次性收藏奖励、最近 8 场战绩；重复结算去重，练习/教学不计进度。联机主动退出也保存已结算的战绩。
10. 新增 progress.js，版本更新为 2.1.0；README 与验收记录更新。

## 使用与边界

运行 node server.js、python tank_server.py 或双击 start-game.cmd，访问 http://localhost:8000/。

当前未部署公网；仅本机/局域网。先到先匹配，需两名玩家；单进程内存房间、JSON 游客档案。服务重启不恢复进行中的房间。专精与最近战绩仅此浏览器保存；排位积分在当前服务器。

尚未做实体 iPhone/Android 多点触控、真实公网弱网和并发压测，不对此作通过声明。后续重点为真实玩家平衡性试玩、账号恢复、匹配分段及防刷分。
